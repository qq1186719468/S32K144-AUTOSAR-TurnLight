## 已确认的应用链路

- `TurnLight_Runnable_10ms`：读取 Hazard、紧急制动、点火、转向开关、车速及反馈信号。
- `TurnLightArb_Runnable_10ms`：对左/右/双闪等请求做优先级仲裁，输出四路灯控制命令。
- `TurnLightAct_Runnable_10ms`：实现普通闪烁、短闪/双闪节拍，并通过四个 IoHwAb Function Client 执行。
- RTE 读接口部分连接到 `Com_ReceiveSignal`；执行层通过 `Rte_Call_IoHwAb_TurnLightCtrlCmd_*_Operation` 调用 IoHwAb。

## 工程注意事项

压缩包中的 `IarStartApp.eww` 包含旧电脑上的相对工程路径，直接打开工作区可能找不到项目。本次验证使用同目录下的 `ASR_S32K144_Start.ewp` 直接构建，因此验证的是源码和配置本身，而不是旧工作区路径。

21 个警告来自既有底软及 IoHwAb/CAN/Com/Nm 等代码；本次没有新增错误。下载到 S32K144 实板、用 CANoe 发送真实输入并观察灯输出，仍需在本机硬件连接后完成。

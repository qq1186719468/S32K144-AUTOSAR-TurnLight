# S32K144 V1.3 学习板与转向灯工程对应关系

## 板载 LED

原理图第 1 页确认 LED2~LED5 分别连接 `PTD0`、`PTD1`、`PTD15`、`PTD16`，与 `Cdd_IoHwAb.c` 四个输出完全对应。LED 阳极经电阻接 `VCC_5V`，因此为低电平点亮。`TurnLightAct.c` 在调用 IoHwAb 前对控制命令取反，已经适配该低有效硬件。

## CAN 通道

板上有两条 CAN 路径：

- TJA1050 收发器：`PTA13/CAN1_TX`、`PTA12/CAN1_RX`，外接接口为 `J6`。
- UJA1169 SBC 内置收发器：MCU `PTE5/CAN0_TX`、`PTE4/CAN0_RX` 经 `J1` 跳线连接到 `SBC_CAN_TX/RX`，总线接口在 SBC 区域的 `J3`。

当前转向灯工程的 `Can_Lcfg.c` 使用 FlexCAN0，故应使用第二条路径：安装 J1 上 PTE5-SBC_CAN_TX、PTE4-SBC_CAN_RX 的跳线；若工程由 CanTrcv/SBC 通过 SPI 管理收发器模式，还需安装 SBC_CS、SBC_MOSI、SBC_MISO、SBC_SCK 对应跳线。CANoe 连接 SBC 区域 CANH/CANL（J3），500 kbit/s。

不要把 CANoe 接到 J6 后仍期待当前 CAN0 工程收发；J6 对应 CAN1，除非另行把工程改为 CAN1/PTA12/PTA13。
